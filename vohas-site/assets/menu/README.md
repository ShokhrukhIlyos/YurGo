# Menu photos

Drop dish photos here. Each photo's filename must match the `img` field in
[`../../menu-data.js`](../../menu-data.js), e.g.:

```
english-breakfast.jpg
vohas-signature-breakfast.jpg
salmon-steak.jpg
...
```

Recommended: JPG, roughly 1000×750px (4:3), under 300KB each so the menu page
loads fast. Any item missing a photo automatically falls back to
`placeholder.svg` — nothing breaks if photos arrive gradually.

To update a dish's description, edit the `desc` field for that item in
`menu-data.js`.
