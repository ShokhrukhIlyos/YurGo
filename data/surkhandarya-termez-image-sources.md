# Surkhandarya / Termez Image Source List

This file collects image-search and source links for each YurGo destination. The goal is to help collect at least 4 usable pictures per place later.

Important: Do not copy photos into the app unless the license is clear or YurGo has permission. Prefer:

- YurGo's own photos.
- Photos from local partners/providers with written permission.
- Wikimedia Commons images with compatible licenses and attribution.
- Official tourism images only if reuse permission is confirmed.

Updated: 2026-08-10

## Recommended Image Fields For The App

Each final image record should store:

- Destination name
- Image URL or local file path
- Photographer / owner
- License
- Attribution text
- Source page URL
- Date downloaded or added
- Whether commercial reuse is allowed
- Caption
- Alt text
- Verification status
